# Regional Demand Forecasting & Expansion Prioritisation

## Business problem
A building-supplies retailer (fictional) operates branches across New
Zealand regions. It overstocks in some regions, runs out in others, and
has no data-driven way to choose where to open its next branch.

## Decision this project supports
1. How much stock to hold in each region over the next 3-12 months
2. Which region to prioritise for the next branch

## Stakeholder
Head of Operations (non-technical, needs clear recommendations)

## Data
Official Stats NZ data via the Aotearoa Data Explorer API (details to
follow).
